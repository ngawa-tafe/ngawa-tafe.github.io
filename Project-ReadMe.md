# Personal Portfolio Website
## Project Overview
This project is a personal portfolio website designed to showcase my coding skills and completed projects. 
It will include several pages such as Home, About, Resume, Contact, Projects, and Sample Project pages. 
The site is built using semantic HTML, Tailwind CSS for styling, and vanilla JavaScript for interactivity.
